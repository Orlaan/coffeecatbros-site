# Coffee Cat Bros

Minimal static website for Coffee Cat Bros.

Live URLs:

- Netlify: https://coffeecatbros-site.netlify.app/
- GitHub Pages: https://orlaan.github.io/coffeecatbros-site/

## Local Preview

Open `index.html` in a browser.

## Deploy

This folder is ready for static hosting.

- Netlify: `netlify.toml` publishes the repository root.
- Railway/Railpack: the root `index.html` and `Staticfile` make static serving explicit.
- GitHub Pages: works from the `main` branch root.
